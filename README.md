# Nice Bolos API

O site ao qual essa API pretende servir é um site de uma loja de doces e salgados,
no qual o cliente poderá fazer encomendas depois de verificar seu número do WhatsApp.
Após a verificação, a API, em conjunto com a https://github.com/devlikeapro/waha, abre
uma conversa com o cliente para finalizar o pedido. Por enquanto, a API, que é
desenvolvida em Java usando Spring Boot, somente verifica
se o numero existe e se o pedido é valido antes de enviá-lo.
